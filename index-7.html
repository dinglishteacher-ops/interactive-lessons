Part 1

Zero Conditional

Коли щось відбувається завжди

If / When + Present Simple , Present Simple
  • факти та закони природи: If you heat ice, it melts.
  • звички — те, що з тобою стається щоразу: If I drink coffee late, I can't sleep.
  • інструкції та поради — у другій частині наказовий спосіб: If you feel cold, put on a jumper.
💡 Тут if = when (щоразу, коли). Якщо if на початку — ставимо кому. Якщо в середині — коми немає: Ice melts if you heat it.

Part 2

First Conditional

Реальна ситуація в майбутньому

If + Present Simple , will / won't + V

If it rains tomorrow, we'll stay at home. — Можливо, піде дощ, і тоді ось результат.

⚠️ Після if ніколи не ставимо will: ❌ If it will rain → ✅ If it rains. Те саме після when, as soon as, unless.
  • Замість will можна: might / may (можливо) — If you're lucky, you might win; can; наказовий спосіб — If you see Max, say hi.
if — якщо (може статися, а може й ні)
when — коли (точно станеться)
as soon as — щойно, як тільки
unless = if … not. Після unless — стверджувальна форма: Unless you hurry ✅ / Unless you don't hurry ❌

    Part 3

    Zero or First?

    Завжди — чи цього разу?

    Zero — загальне правило, так буває завжди:
    If you leave chocolate in the sun, it melts.
    First — конкретна ситуація в майбутньому:
    If you leave this chocolate in the car today, it will melt.
    🔎 Підказки: today, tomorrow, tonight, this, my, your + конкретна річ → швидше First. always, usually, people, загальні речі (cacti, chocolate) → швидше Zero.
